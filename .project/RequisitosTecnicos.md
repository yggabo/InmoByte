# Diseño y creación de una Base de Datos con Backend que dé soporte estructurado a la gestión de datos

Diseñar y crear un modelo de persistencia de datos con un motor SGBD de tipo SQL, con un backend en Python con flask que dé soporte a una aplicación que resuelva una funcionalidad compleja.

## Tecnologías
- Docker
- Git  
- SCRUM  
- Linux  
- Flask  
- JSON  
- Web Services  
- MariaDB  

---

## Contexto del proyecto

Dentro de un proyecto conjunto para un cliente, se crea la lógica de negocio de una aplicación cuyo punto inicial es una Base de Datos que contiene la organización de información de una estructura compleja con varias entidades o modelos.

La base de datos debe generar un diagrama de entre **9 y 15 entidades**.

1. Modelo literario  
2. Modelo entidad-relación  
3. Modelo relacional  
4. Modelo de código  

Motores asignados:
- MariaDB
